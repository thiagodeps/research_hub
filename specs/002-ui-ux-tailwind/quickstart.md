# Quickstart

## Configuração do Frontend com Tailwind CSS

1. **Instalar Dependências**
   No diretório `frontend/`, execute:
   ```bash
   npx astro add tailwind
   ```
   *(Este comando já configura o arquivo `astro.config.mjs` e cria o `tailwind.config.mjs` automaticamente)*

2. **Rodar o ambiente de Desenvolvimento**
   ```bash
   npm run dev -- --port 4321
   ```

3. **Validação Visual**
   - Acesse `http://localhost:4321/login` e reduza o tamanho da janela para testar a responsividade (split screen -> stack).
   - Teste o hover nas linhas das tabelas do dashboard.
