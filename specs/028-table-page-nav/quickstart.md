# Quickstart

This feature does not require any new setup or installation steps. It modifies the existing `EntityPage.jsx` component to add a page number input.

To test:
1. Run the application.
2. Open any entity page with enough records to have multiple pages (e.g., more than 50).
3. Try typing a page number in the new input field in the pagination controls at the bottom of the table.
4. Verify the table data updates to the correct page.
